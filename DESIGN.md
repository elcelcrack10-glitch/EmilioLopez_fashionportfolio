## Adaptation for Emilio Lopez — 2026-10-01

The reference above is retained as supplied by Inspo. The portfolio implementation uses its photographic entry, spacious personal introduction, strong hierarchy and selective yellow/pastel accents. Live inspection confirmed a white page canvas and yellow/pink/green tokens; the yellow cookie panel is not evidence that every page should be yellow.

### Design contract

- Make the home entry feel like entering Emilio's creative world: use the approved Feel Marni running image at large scale, his name and a direct project link. Keep a readable title/navigation even if the image fails to load.
- Retain Albert Sans, the user's latest typography choice. Do not import Futura, imitate Jeffers' lettering or use his studio photographs.
- Add a centered personal introduction derived from Emilio's biography, then the four existing projects with both Recorrido and Índice views.
- Use warm paper for reading, yellow for a few important controls and the contact area, and a pale green process/about feature using Emilio's own toile photograph.
- Keep approved project covers, credits, process orders, ES/EN switching, CV and contact links. Maintain the existing project reading navigation.
- On mobile, display the full landscape hero photograph between the header and title rather than cropping away the work. Keep all navigation directly available.
- Use native links and existing interactions. No loading gate, forced horizontal scrolling, autoplay, cursor replacement or animation library.
- Work from the existing CSS system with 8px-based spacing. Verify font/image loading, focus, contrast, reduced motion and layouts at 320/768/1024/1440px before delivery.
